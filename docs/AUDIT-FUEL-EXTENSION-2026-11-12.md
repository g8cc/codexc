# CodingKeeper 燃料扩展复审 · 2026-11-12

本轮以刚加入的 32 类燃料为起点，复审目录、容量、持久化轮转、加料、待决策交接、晨报及实际 runner 接入。保留上一轮和其他 Agent 的改动，历史审计见 [AUDIT-2026-11-12.md](AUDIT-2026-11-12.md)。

## 扩展结果

- 通用方向从 32 增至 **44**：补充领域适用性、数据完整性、版本兼容、资源生命周期、并发、维护体验、产品测量、协作、用户控制、支持复现、信息组织及假设验证。
- 新增 **17 个可组合领域包、85 个方向**，内置可用总数 **129**。具体目录及项目匹配见 [FUEL-DOMAINS.md](FUEL-DOMAINS.md)。
- 领域默认不启用。Agent 按已有代码、产品与测试证据选择；Keeper 只校验、原子保存和轮换，不按名字猜业务。
- `ck prompts packs/list --all/enable/disable` 支持检查和配置；项目 profile、进程环境覆盖及显式方向筛选的优先级明确。
- 自定义文件上限 128，合并目录上限 512；全部内置和满额自定义共 257 类可同时轮换，原 ID、自定义覆盖和旧游标兼容。

方向可沿实际能力、用户状态、数据/时间边界、失败模式和支持平台继续展开；每轮仍要求一个真实差距及可验收成果，不用目录数量替代价值。

## 发现与修复

| 问题 | 根因与修复 | 回归 |
|---|---|---|
| 筛选目录后可以加入导致下轮非法的燃料 | 加料容量依赖筛选结果；改为自定义容量独立检查、锁内检查，并扩展合并容量 | 96 个自定义加料旧版成功后 next 失败；满额目录及最后位置并发回归 |
| 显式筛选导致无法查看其他方向 | show 使用运行目录；改用全部可用目录，查看不启用领域 | 筛选 security 后查看 onboarding；查看未启用 rag-citations |
| 同一待决策事项换文本反复入队 | 只按全文去重；增加待决策 `DECISION-*` ID 冲突检测，保留已有文本，精确重复幂等 | 相同 DECISION-PRICING、不同证据旧版生成两项，修复后拒绝第二项 |
| 活动目录变化未重开扫描，检查/取下一项之间变化可被吞掉 | 游标只有下标；加入有序目录/合同签名和独立确认签名，变化重置位置和无产出计数 | 活动新增、顺序变化、检查间启用、耗尽间变化、旧格式及损坏签名 |
| 晨报把未来状态当新鲜、小数时间当陈旧 | 类型和单向时间判断不完整；允许 int/float、-5..120 秒时间差 | 未来一小时及当前小数时间两项旧版失败；JSON/文本状态读取 |
| 首次 headless 自动初始化在新日志目录下失败 | shell 先打开重定向，日志目录尚未准备；先通过共享 logger 准备/迁移，再执行初始化 | 新 HOME 与旧日志历史，旧版 exit 1，修复后脚手架输出及旧历史均保留 |

实现自审另复现两项问题：启用包丢失已有 profile 附加证据字段；损坏耗尽标记在失败前部分确认新游标。均先加失败用例，再修复为保留附加字段、完成状态校验后再确认变化。

新配置使用 acceptance.lock 和原子发布；无效版本、未知/重复 ID、符号链接、FIFO 被拒绝。启用/禁用幂等，且不改 queue/halt。明确环境覆盖，避免将配置领域误报为旧 runner 的实际生效领域。
